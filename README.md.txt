# Student Management System

## Project Description

This project is a Student Management System developed using HTML, CSS, and JavaScript following Object-Oriented Programming (OOP) principles.

The system allows users to:

- Create Students
- Create Courses
- Enroll Students in Courses
- View all Students
- View all Courses
- View all Enrollments
- View all records through a Dashboard

## Classes Used

### Student

Stores student information:

- ID
- First Name
- Last Name
- Email

### Course

Stores course information:

- ID
- Course Name

### Enrollment

Stores enrollment information:

- Student ID
- Course ID

## Features

### Student Management

- Add new students
- Display all students

### Course Management

- Add new courses
- Display all courses

### Enrollment Management

- Enroll students in courses
- Prevent duplicate enrollments
- Validate Student ID and Course ID

### Dashboard

Displays:

- Total Students
- Total Courses
- Total Enrollments
- Student records
- Course records
- Enrollment records

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Object-Oriented Programming (OOP)
